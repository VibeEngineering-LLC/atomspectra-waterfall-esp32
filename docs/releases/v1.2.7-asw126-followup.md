## Highlights

Follow-up on tag **`firmware-v1.2.6`**. The v1.2.6 P0 quiet-write hang/durability items stay closed. This tag does **not** restore live-USB per-row `fsync` and does **not** lengthen the quiet budget.

**Heap / pin**

- HTTP Reset no longer `fclose`/`free`s sliced-autosave state from httpd. Abort is a flag; the main task consumes it (`spectrum_autosave_consume_abort`) and also unlinks `current.bin` so Reset survives reboot.
- Successful waterfall offload always unpins. Failed quiet-unlink marks a single-flight zombie so the same file is not claimed again; the keep-last ring may still delete it.

**Reliability**

- Histogram staging continuity is the host-tested helper (`UINT32_MAX` idle); `spectrum_process_histogram_chunk` calls it.
- Waterfall row pack is a static PSRAM buffer (`WF_ROW_STRIDE`), allocated in `spectrogram_init`.
- `s_fs_quiet_sig` is Taken only by `wf_fs_task` (httpd/offload use delay fallback).
- `http_io_gate` wraps fopen/fwrite/rename only, not commit-wait loops.

**Hygiene**

- `s_wf_epoch` after `make_room` (do not use `!recording` — that would skip stop-drain writes).
- `seg_write_row` is `void`; `COMMIT_LISTENERS_MAX` is 6.
- Quiet budget SOT remains `FLASH_QUIET_BUDGET_MS`.
- CI `build.yml` uploads `atomspectra_gw.bin` + SHA256 on `firmware-v*` tags. Release Docker binaries are still the issue-#9 compare path.

Write-up: [`docs/bugs/2026-08-13-asw126-audit-followup.md`](../bugs/2026-08-13-asw126-audit-followup.md).
