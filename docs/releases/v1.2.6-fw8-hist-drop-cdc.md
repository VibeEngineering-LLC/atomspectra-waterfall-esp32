## Highlights

1. **#FW-8 residual — hist `sweep dropped` metronome**  
   LittleFS autosave (~33 KiB) and waterfall segment flash starved the USB FTDI FIFO in the post-commit quiet window → staging gaps → intentional #FW-8 drops (~70/h WF OFF, ~80/h WF ON).  
   **Fix:** shared quiet-budget helper; sliced autosave (`current.bin.tmp` → rename); no live `fsync`; WF baseline/rows sliced; quiet gap after finalize; quiet `unlink` for offload/ring; skip autosave on commit-wait timeout while USB live.  
   Write-up: [`docs/bugs/2026-08-12-histogram-sweep-drops-autosave.md`](../bugs/2026-08-12-histogram-sweep-drops-autosave.md).

2. **#FW-51 / #FW-43 residual — CDC reconnect races**  
   Defer RX ring / SHPROTO reset to `usb_rx_worker` (alien `xStreamBufferReset` was racy). Split teardown watchdog (15 s) from `is_connected` stale (8 s). Hold TX mutex across `-inf` retry; restore 512 B text command buffer.

3. **Docs**  
   Public sanitization of #FW-51 / #FW-52 / v1.2.5 notes (no lab host identifiers).
