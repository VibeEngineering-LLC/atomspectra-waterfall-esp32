## #FW-51 — silent CDC stall (product bug)

**Symptom:** Analyzer counts stop; UI/API still report connected; no reconnect.

**Root cause:** `CDC_ACM_HOST_ERROR` was log-only; close only on `DEVICE_DISCONNECTED` (which did not fire). `usb_host_cdc_is_connected()` == handle non-NULL. `#FW-43` `spectrometer_dead()` intentionally returns false when RX is stale.

**Fix (shipped in `235ee52`, refined in v1.2.5 tree):**

1. `cdc_teardown(reason)` — mutex-claim handle → NULL + `cdc_open=false` → close.
2. `CDC_ACM_HOST_ERROR` → teardown (`error`).
3. RX watchdog / empty bus in `usb_connect_task` (≥10 s open, then `rx_age≥8s` or `bus_devs_now==0`).
4. `usb_host_cdc_is_connected()` — handle + fresh RX after 5 s grace.
5. `/api/usb-diag`: `cdc_error_count`, `rx_watchdog_trips`, `bus_empty_trips`, `reconnect_ok`, `last_fault_*`.

**HW verify:** unplug >15 s → `last_fault_reason=1 (disconnect)`, `reconnect_ok≥1`, live again.

## #FW-43 follow-on — hotplug “dead” banner / Retry (v1.2.5)

**Symptom after CDC reconnect:** Banner claims power-cycle the **gateway**; Start/`-sta` TX OK but no SHPROTO; Retry button felt broken.

**Causes (layered):**

| Layer | Mechanism |
|---|---|
| Hardware | FTDI bus-powered keep-alive (`01 60`) without MCU UART → classic #FW-43; often needs **spectrometer** USB unplug/replug (VBUS edge), not only soft reopen. |
| Firmware | RX SHPROTO state not reset on teardown/open; one `-inf` without retry; recover closed CDC from httpd → **reboot**. |
| UI | `setDeadBanner(true)` rebuilt HTML every poll → destroyed Retry mid-click. |
| Diag | `usb_host_send_text_command` advanced `cmd` then `strncpy` → empty `last_tx_cmd`. |

**Fix:**

1. `cdc_reset_rx_path()` on teardown + open (SHPROTO init + RX ring drain).
2. Reconnect: longer FTDI settle + up to 4× `-inf` until SHPROTO.
3. Banner text + **Повторить связь** → `POST /api/usb/recover` (deferred teardown on `usb_conn`).
4. Banner HTML built once per on-transition.
5. `last_shproto_ts_ms` on `/api/usb-diag`; fixed `last_tx_cmd`.

**HW verify:** spectrometer USB ~10 s cycle → `dead=0`, counts grow; live recover → `fault=5`, no reboot, SHPROTO resumes.
