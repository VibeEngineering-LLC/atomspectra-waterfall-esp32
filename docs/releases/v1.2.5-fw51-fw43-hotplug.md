## #FW-51 — silent CDC stall

**Root cause:** `CDC_ACM_HOST_ERROR` was log-only; close only on `DEVICE_DISCONNECTED`. `is_connected()` == handle non-NULL.

**Fix:** `cdc_teardown`, ERROR→teardown, RX/bus watchdog, honest `is_connected`, `/api/usb-diag` counters.

**HW verify:** unplug → `last_fault=disconnect`, `reconnect_ok≥1`, live again.

---

## #FW-43 follow-on — hotplug soft-lock

**Causes:** stale RX SHPROTO; one `-inf`; recover from httpd → reboot; UI banner rebuild; empty `last_tx_cmd`.

**Fix:** RX reset on worker task, `-inf` retries, deferred recover, Retry UI, `last_shproto_ts_ms`.

**Note:** soft recover cannot invent a spectrometer MCU VBUS edge.

## #FW-52

`sys_evt` overflow with dbglog ON → boot-loop after RESET. Evidence: `docs/bugs/2026-08-05-sys-evt-boot-loop-fw52/`.
