## Highlights

Vendor: after instrument cold start, T1 is invalid for ≥4 s. The gateway gates on **CDC-open**, not field `t`.

- First parsed `-inf` of a USB session: publish `VERSION` / `POT` / `t`; T1 is `NaN` (JSON `null`) even if the token is numeric.
- Hold stays active for `SPECTRUM_T1_REFRESH_MS` (5 s) after CDC-open, so reconnect retries and `/api/settings/backup` in that window also stay `null`.
- Exactly one follow-up `-inf` ~5–7 s after open, only if the first reply arrived.
- `OFF` token → `NaN` → JSON `null` (not 0 °C). T2/T3 sanitize only; not held.
- `#FW-13` 30-minute tick is unchanged and does not reset the T1 session.
- `-rst` mid-session after settle does not force T1 back to `null`.

Docker binaries for this tip are **not** in git. Compare SHA256 below; artifacts go on a fork `refbuild-…` GitHub Release when the PR is opened.
