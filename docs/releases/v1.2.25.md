# 1.2.25 — Stop/Reset no longer ignored after a board restart

**Date:** 2026-09-26
**Base:** `main` at 1.2.24
**Scope:** Web UI only (5 pages); firmware C code unchanged.

Private lab identifiers (LAN IP, MAC, board-id, absolute paths) are **not** published here.

---

## Русское резюме (для GitHub-релиза)

**Кнопки «Стоп» и «Сброс» снова работают сразу после перезагрузки платы.** Защитный токен
веб-интерфейса (CSRF) плата выдаёт заново при каждом включении. Если вкладка браузера
оставалась открытой, пока плата выключалась (например, её переносили), страница продолжала
отправлять команды со старым токеном — плата их отклоняла, а страница об этом молчала:
набор продолжался, спектр не сбрасывался, пока вкладку не обновляли вручную.

Теперь при таком отказе страница сама получает новый токен и повторяет команду один раз.
Касается всех кнопок, отправляющих команды: «Старт/Стоп», «Сброс», сохранение, настройки,
удаление записей, водопад.

После обновления прошивки откройте страницы платы заново (F5) — старые вкладки ещё со старым
кодом.

---

## What changed

- `post()` on `index`, `saved`, `service`, `system` and `waterfall` pages: on HTTP 403 it
  re-fetches `/api/csrf-token` and retries the request exactly once. A request with a valid
  token is still sent once (no extra traffic).
- `demo/` copies of the same pages updated identically.
- New host test `test/web/csrf_retry_test.mjs` (Node): extracts `post()` from each page and
  runs it against a mock board with a rotated token.
